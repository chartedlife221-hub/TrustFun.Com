# TrustFUN v2

A secure Solana meme coin launchpad with SPL token creation, Metaplex metadata, IPFS storage, wallet integration, bonding curves, and decentralized trading.

## Project Structure

```
TrustFun-V2/
├── frontend/     - Web UI and client-side applications
├── backend/      - Server-side logic and APIs
├── shared/       - Shared utilities, types, and constants
├── docs/         - Project documentation
└── README.md     - This file
```

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn
- Git

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

## Features

- SPL token creation
- Metaplex metadata integration
- IPFS storage support
- Wallet integration
- Bonding curves
- Decentralized trading
- Anti-rug protection
- Liquidity locks
- Creator verification
- AI-powered trust scoring
